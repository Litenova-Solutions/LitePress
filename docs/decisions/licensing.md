# LitePress Licensing

| Field | Value |
|:---|:---|
| Status | Accepted |

---

## Context

LitePress is a public reference implementation of Litenova Engineering Standards and the company showcase blog. We want individuals to fork and run personal blogs freely, while commercial and organizational use requires a paid license from Litenova Solutions.

---

## Decision

1. License the software under **[PolyForm Noncommercial License 1.0.0](https://polyformproject.org/licenses/noncommercial/1.0.0)**.
2. Publish **[COMMERCIAL-LICENSE.md](../../COMMERCIAL-LICENSE.md)** describing when a commercial license is required and how to contact Litenova Solutions.
3. Copyright holder: **Litenova Solutions** (`Required Notice` in `LICENSE`).

---

## Who can use LitePress for free

- Individuals for personal, noncommercial blogs (hobby, portfolio without a commercial entity operating the site as a business product).
- Noncommercial organizations as defined by PolyForm (charities, schools, public research, etc.).
- Contributors learning from or improving the codebase under the same license.

---

## Who must contact Litenova Solutions

- Any **company** using LitePress for an official blog, marketing site, or internal publishing (PolyForm defines *your company* broadly).
- Hosting providers offering LitePress as a service.
- Agencies deploying LitePress for paying clients.

See [COMMERCIAL-LICENSE.md](../../COMMERCIAL-LICENSE.md) for the summary table.

---

## Consequences

- LitePress is **not** OSI-open-source; it is **source-available** with noncommercial terms.
- README and docs must link to `LICENSE` and `COMMERCIAL-LICENSE.md`.
- MIT license (previous) is superseded for new downloads from this commit forward.
